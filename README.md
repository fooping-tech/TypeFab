# TypeFab

**文字を、かたちに。** GitHub Pagesで動く、日本語対応のレーザー加工向けタイポグラフィSVGエディタ。

公開サイト: **https://fooping-tech.github.io/TypeFab/**

## はじめて使う

1. サイトを開き、サンプルの文字をクリックします。
2. 右側で文字内容、日本語フォント、サイズ、字間、位置、回転を変更します。入力はフォーカスを外すと確定します。
3. ツールバーの「文字」「長方形」「楕円」「線分」を選び、加工エリアをクリックして追加します。オブジェクトはドラッグで自由配置できます。
4. 「ブリッジ」を選び、切り残したい輪郭上をクリックします。オレンジ色の長方形が**実際にカット線から除去される領域**です。幅・高さ・回転を右側で調整できます。
5. 「自動ブリッジ」は、まだ切り残しがない各閉輪郭に1.5 mm角の保持用ブリッジを追加します。内側の島や外形を材料に保持する用途です。
6. 「加工プレビュー」で赤いカット線と線の途切れを確認し、「SVGを書き出す」でダウンロードします。
7. 加工ソフトでmm寸法とカット設定を確認し、材料に合わせてテスト加工してください。

### 編集と保存

- 「アウトライン化」で選択中の文字を固定パスに変換します。SVG出力は、この操作をしなくても常にアウトラインです。
- 「保存」は編集用JSON、「開く」はその復元です。ブラウザにも自動保存します。
- JSONには文字の輪郭が保存されるので、追加フォントを再読み込みしなくても表示・移動・SVG出力ができます。文字内容・書体などを再編集するには元のフォントを追加し、選び直してください。
- 「新規」は空のプロジェクトを作成します。取り消し可能です。
- Ctrl/⌘ Z: 元に戻す、Ctrl/⌘ Shift Z: やり直す、Delete: 削除、矢印: 0.5 mm移動、Shift+矢印: 5 mm移動。
- 1 mmスナップ、ズーム、オブジェクト複製、加工エリア寸法変更に対応。
- スマートフォンは簡易レイアウトです。精密編集にはPCを推奨します。

## フォント

同梱書体は **Zen Kaku Gothic New Regular**（ゴシック）と **しっぽり明朝 Regular**（明朝）。書体プレビュー付きです。TTF / OTF / WOFFを端末から追加できます。フォント・入力テキスト・プロジェクトを外部サーバーに送信しません。

- カスタムフォントはセッション内のみ。WOFF2 / TTCは未対応です。
- フォントにない文字はエラーを表示し、無断で別の文字に置き換えません。
- 「縦に配置」は文字を縦に並べる簡易機能です。縦書き専用字形・約物回転・高度な組版には未対応です。
- Google Fonts配布のSIL Open Font License 1.1に従って再配布しています。各ライセンスは `public/fonts/` に同梱しています。
- 配布元: [Zen Kaku Gothic New](https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew)、[Shippori Mincho](https://github.com/google/fonts/tree/main/ofl/shipporimincho)。

## 加工データとMVPの範囲

SVGはmm単位、`viewBox`付き、赤色・塗りなしのパスです。文字参照、画像、マスク、クリップ領域は残しません。ブリッジの境界を新しいカット線で囲むことはせず、元の輪郭に開いた隙間を作ります。文字のBezier曲線は許容誤差 **0.02 mm** で線分近似します。画面の加工プレビューとエクスポートは同じ形状処理を使います。

「切り残しなし」は、閉輪郭にブリッジによる隙間があるかの検査です。**材料の連結性、重なった形状全体の保持、物理的な強度を保証するものではありません。** 自動配置後も位置・幅を確認してください。加工後に完全に切り抜いた文字を一体化するUnionや、板との構造接続を自動設計する機能ではありません。

MVPではカーフ補正、重複線除去、図形のUnion/Difference、拘束、円弧、DXF、レーザー直接制御には対応していません。重なりのある図形のカット線もそのまま出力します。エリア外のカット線や、ブリッジで完全に隠れた輪郭がある場合は出力を止めます。

## 開発

Node.js 22以降で実行します。

```sh
npm ci
npm run dev
npm test
npm run build
```

ローカル: http://127.0.0.1:5173/TypeFab/

Vite + JavaScript + opentype.jsの完全静的構成です。`src/geometry.js` が輪郭・ブリッジ・SVG出力、`src/project.js` がJSON入力検証、`src/main.js` が編集UIを担当します。将来別リポジトリ名へ移す場合は `vite.config.js` の `base` を変更してください。

## GitHub Pages

Settings → Pages → Build and deployment → Sourceを **GitHub Actions** に設定します。`main` へのpushで `.github/workflows/pages.yml` がテスト・ビルドを実行し、Pagesへ公開します。ビルドが失敗した場合はデプロイしません。

## 検証の境界

自動テストではブリッジの線分除去、回転、複数隙間、自動配置、両書体の日本語輪郭、SVG形式、JSON入力検証を確認します。ブラウザの操作確認とGitHub Pagesへの公開確認は `PLANS.md` に記録します。実機レーザー加工・材料強度・加工ソフト全種類での互換性は未検証です。
