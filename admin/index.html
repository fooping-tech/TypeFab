管理者トークン

Cloudflare Access が設定されていない環境（ローカル開発）です。Workers の ADMIN_TOKEN を入力します。このブラウザのタブにのみ保存します。

 

Cloudflare Access のログインが必要です

この管理画面と /api/admin/* は Cloudflare Access で保護されています。ページを再読み込みして Access にログインしてください。Access アプリケーションの対象パスに /admin と /api/admin の両方が含まれていることを確認してください。

保持期限切れの個人情報・SVGの削除

完了（COMPLETED）またはキャンセル（CANCELLED）から 90 日を過ぎた注文の氏名・メールアドレス・住所・電話番号を消去し、R2 の SVG を削除します。注文番号・金額・日付・Stripe の ID・加工内容・状態は残ります。毎日 03:00（JST）に Cron Trigger で自動実行され、ここから手動でも実行できます。
