LASER-CUT TYPOGRAPHY · BROWSER-BASED · FREE

Turn words into laser-cuttable designs.

文字を、切れるデザインへ。 入力した文字を、レーザー加工可能なSVGへ。日本語フォント8書体、レイアウト、ブリッジ、スマート接続、ベクター編集、2D CADまで、ブラウザだけで完結します。

BEFORE / AFTER

Typography is not automatically laser-cuttable.

普通のフォントをそのままレーザーカットすると、O・A・P・R・B・8・0 や日本語の「日」「あ」のような閉じた部分の内側が脱落します。 TypeFabは、ふつうの文字を 加工できる形状 に変えます。

  1. 01 NORMAL FONT

    フォントのままの文字。内側の「島」は外側とつながっていません。

  2. 02 OUTLINE

    輪郭をカット線にします。切り抜くと、島は板から落ちます。

  3. 03 BRIDGE ADDED

    島と外側をつなぐ非カット帯（ブリッジ）を自動で追加します。幅は調整できます。

  4. 04 LASER-CUT READY

    実際に出力されるカット線。帯の側面も含めた閉じた輪郭で、島が一体になります。

上の図は同梱フォント（Zen Kaku Gothic New / しっぽり明朝）から src/geometry.js が生成した実際の輪郭と自動ブリッジ（幅 1.5 mm）です。

TypeFab turns ordinary type into manufacturable geometry.

PRODUCT

Everything from type to cut path, in one window.

文字を打つだけ

テキストを入力すると、その場で輪郭になります。ダブルクリックでキャンバス上の編集、サイズ・字間・長体・平体、縦書き（OpenType vert/vrt2）に対応。1文字ずつ・部位ごとのグループ化解除で、文字の一部だけを動かすこともできます。

日本語フォント8書体を同梱

Zen Kaku Gothic New、しっぽり明朝、Zen Maru Gothic、Dela Gothic One、RocknRoll One、Kaisei Decol、Zen Kurenaido、DotGothic16。すべて SIL Open Font License 1.1 で、ライセンス本文を同梱しています。選んだフォントだけを読み込み、一覧は各フォントの実際の字形でプレビュー。手元の TTF / OTF / WOFF も追加できます。フォントは端末の外に送信しません。

レイアウトと変形

mm単位の加工エリアにドラッグで配置。回転ハンドル、四隅の拡縮、レイヤー、グループ、整列。エンベロープ変形（ワープ）で文字の輪郭そのものを曲げられます。

ベクター編集

文字をアウトライン化すると、フォントのベジェ曲線そのままのパスになります。アンカーとハンドルを直接動かし、追加・削除・スムーズ／コーナー切り替え、SVG path d の直接編集も。

ブリッジ

「選択にブリッジ」で穴を検出し、島と外側をつなぐ帯を自動追加。手動ブリッジは任意の位置・角度で置けます。幅・高さ・回転を後から調整できます。

スマート接続

ステンシルとは逆に、文字そのものを1枚で切り出したいときに。離れた文字や文字内の部位を接続形状でつなぎ、1つの閉じた輪郭にします。幅・最大距離、Smooth / Tapered / Rounded / Straight のスタイル、日本語の筆画方向を優先する候補選び。確定前に接続の移動・削除・追加・候補の切り替えができ、確定後は通常のパスとして編集できます。

2D CAD

正多角形、ミラー、矩形／円形パターン、オフセット、トリム・延長、フィレット・面取り、計測、参照寸法。拘束なしの2D編集で、結果は通常のパスになります。寸法は図面上の参照のみで、SVGには出力しません。

図形と図形演算

長方形（フィレット付き）、楕円、正多角形、線分。結合・切り抜き・交差・XOR で文字と図形を組み合わせ、1つのカット形状にします。SVGファイルの読み込み（path / rect / circle / ellipse / line / polyline / polygon、transform、Inkscapeレイヤー）にも対応。

SVG書き出し

加工プレビューの赤線がそのまま出力されます。mm単位・viewBox付き・パスのみ。text / mask / clipPath / image を含まないので、加工ソフトでそのまま読めます。

BRIDGE

Built for things that actually get cut.

きれいなSVGでも、切ったあとに部品が落ちては意味がありません。TypeFabでは、必要な場所にブリッジを追加し、その幅と位置を自分で制御できます。

「切り残しなし」の検査は、閉じた輪郭にブリッジの隙間があるかを確認するものです。材料の連結性や物理的な強度を保証するものではありません。材料・厚さに応じて幅を調整し、テスト加工してください。

ステンシルではなく、文字を切り出すなら。

ブリッジは「文字の形に穴をあける」ための機能です。文字そのものを1枚の板として切り出したいときは、スマート接続が離れた文字や部位を接続形状でつなぎ、1つの閉じた輪郭にします。

  • 接続の候補 最短距離だけでなく、画の端や向きを見て自然な位置を選びます。日本語は筆画の延長を優先
  • スタイル Smooth・Tapered・Rounded・Straight を自動または手動で。幅と最大距離は数値で指定
  • 確定前の調整 接続の移動・両端の変更・幅・曲率・削除・次の候補・手動追加。未接続があれば確定できません
  • 結果 1つの固定パス。Undo 1回で元の文字に戻り、パス編集・ワープ・SVG出力はそのまま

VECTOR EDITING

Edit the geometry, not just the text.

  • アンカーポイント クリック・Shift・範囲選択、ドラッグで移動、矢印キーで 0.1 mm
  • ベジェハンドル スムーズは連動、コーナーは独立。Alt で切り離し
  • 移動・回転・拡縮 ドラッグ、回転ハンドル（Shiftで15°）、四隅のハンドル、数値入力
  • パス編集 ノードの追加・削除、直線化、SVG path d の直接編集（M L H V C S Q T A Z）
  • ワープ 4辺のベジェによるエンベロープ変形。Arc・Arch・Wave・Flag・Perspective など
  • 図形演算 結合・切り抜き・交差・XOR。結果は編集できるパス
  • 2D CAD オフセット、トリム・延長、フィレット・面取り、ミラー、矩形／円形パターン、計測、参照寸法

TypeFabで作ったデザインをそのまま加工注文し、切り出した板を受け取れる流れを準備しています。エディタの「このデザインを加工注文する」から注文ページ（SVGの確認・材料・厚さ・数量・納期・料金・Stripe決済）へ進めますが、加工サービスの提供開始まで決済はできません。それまではSVGを書き出し、お手持ちの加工機や加工サービスで切り出してください。

注文前に、使うところまで想像できる。

注文ページでは、SVGの検査と概算に加えて、黒いクラフトペーパーで作るしおりの完成イメージを確認できます。単体、105 × 148 mm の文庫本に挟んだ状態（上部 20 mm）、同じ縮尺でのサイズ比較を実寸比率で描き、幅 50 mm 超や長さ 90 mm 未満・160 mm 超には注意を表示します。
